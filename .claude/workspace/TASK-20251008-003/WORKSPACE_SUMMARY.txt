=================================================================================
VALIDATION FUNCTIONS
=================================================================================

1. validate_task_id(task_id)
   - Validates: ^(TASK|ARCH|HOTFIX|DEVOPS|MTENANT|PROCESS)-[0-9]{8}-[0-9]{3}$
   - Returns: 0 if valid, 1 if invalid
   - Blocks: Command injection via TASK_ID parameter

2. sanitize_path(path, base_dir)
   - Prevents: Directory traversal (..) and absolute path escapes
   - Returns: Canonical path if safe, exits 1 if dangerous
   - Uses: realpath -m for path canonicalization

3. validate_workspace_dir(task_id)
   - Combines: validate_task_id() + sanitize_path()
   - Returns: Canonical workspace path
   - Use case: Before creating workspace directories

4. validate_file_readable(file_path)
   - Checks: File exists (-f) and is readable (-r)
   - Returns: 0 if accessible, 1 otherwise
   - Use case: Before reading tasks.csv or other files
